# Лабораторная работа 1: Приложение каталога .NET пакетов

## Цель работы
Разработка мультиплатформенного приложения (Compose Multiplatform) для навигации, поиска и просмотра каталога библиотек .NET с использованием современной навигации JetBrains Navigation 3, чистой архитектуры и локализации.

## Содержание работы и выполненные требования

1. **Структура Compose Multiplatform:**
   - Код бизнес-логики, экранов, тем и навигации вынесен в общий модуль `:shared` (`commonMain`).
   - Поддерживаются платформы Android (`:app`) и Desktop (`:shared:run`).

2. **Навигация (JetBrains Navigation 3):**
   - Подключена библиотека `org.jetbrains.androidx.navigation3:navigation3-ui`.
   - Удалена зависимость `navigation-compose`.
   - Роуты описаны строгой иерархией типов (`sealed interface Route`):
     - `data object List : Route`
     - `data class Detail(val packageId: String) : Route`
   - Для переходов настроены прямые и обратные анимации сдвига и прозрачности (`transitionSpec` и `popTransitionSpec`).

3. **Данные и репозиторий:**
   - Сетевой слой заменён на локальный репозиторий `PackageRepository` / `MockPackageRepository` с 22+ реалистичными записями .NET пакетов по схеме NuGet API.

4. **Поиск и пустое состояние:**
   - На главном экране реализована поисковая строка в реальном времени.
   - Добавлен экран «Ничего не найдено» при пустом результате поиска с кнопкой сброса запроса.

5. **Архитектура UI и экранов:**
   - Экраны отрисовываются из состояния (`UiState`).
   - В Composable-функции передаются состояние (`uiState`) и колбэки, а не `ViewModel` целиком.

6. **Локализация и паритет строк:**
   - Созданы ресурсы строк для локалей `values` и `values-ru`.
   - Паритет ключей проверен скриптом `tools/check-strings.py` (100% совпадение ключей).
